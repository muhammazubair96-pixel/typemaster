Learn HTML

Learn the most useful HTML tags and elements with simple examples. Write the code and understand what each element does.

1. HTML Heading

Headings are used for titles and section names. HTML provides headings from H1 to H6.

HTML 
<h1>My Website</h1>
<h2>About Me</h2>
<h3>My Skills</h3>
RESULT

My Website

About Me

My Skills

2. Paragraph

The <p> tag is used to create normal text paragraphs.

HTML 
<p>
This is my first paragraph.
</p>
RESULT

This is my first paragraph.

3. Link

Use the <a> tag to create clickable links. 

<a href="https://example.com">
Visit Website
</a>
RESULT
Visit Website

4. Button

The <button> element creates a clickable button. 

<button>
Click Me
</button>
RESULT

5. Input

Input fields allow users to enter information. 

<input
type="text"
placeholder="Enter your name">
RESULT

6. Image

The <img> tag displays an image. 

<img
src="image.jpg"
alt="My Image">

7. Lists

HTML supports ordered and unordered lists. 

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
RESULT
  • HTML
  • CSS
  • JavaScript

8. Form

Forms are used to collect information from users. 

<form>

    <label>Name</label>

    <input type="text">

    <button>
        Submit
    </button>

</form>
